**📊 Sales Performance Analytics Dashboard**

SQL | Power BI | Business Intelligence
- - -

**🔍 Executive Summary**

This project analyzes sales transaction data to identify key revenue drivers, product performance trends, and regional sales distribution. Using SQL for data modeling and Power BI for visualization, the dashboard provides interactive insights to support business decision-making and sales performance monitoring.

**🎯 Business Problem**

- Sales teams require clear visibility into product demand, regional performance, and customer purchasing behavior to optimize revenue growth.

- The objective of this project was to:

- Analyze overall sales performance

- Identify top-performing products and regions

- Understand customer purchasing trends

- Compare actual sales performance against budget allocations

- Enable data-driven business insights through dashboards

**📁 Dataset Overview**

The project uses a structured relational dataset containing multiple business dimensions:

- Customers Dataset – customer identifiers and names

- Products Dataset – product catalog and identifiers

- Regions Dataset – geographical sales regions

- Budgets Dataset – planned product budgets

**Sales Orders Dataset – transaction-level sales data**

The dataset includes key attributes such as:

Order number

Order date

Product ID

Customer ID

Sales quantity

Unit price

Total sales amount

Region information

**📈 Key Insights**

- Key findings from the analysis include:

- Certain products contribute significantly higher revenue compared to others

- Regional sales distribution highlights markets with strong product demand

- Customer purchasing patterns show repeat buying behavior

- Budget vs actual sales comparison reveals performance gaps in certain products

- These insights help businesses identify growth opportunities and improve sales strategy.

**🛠 Technical Implementation**

The project was implemented using the following steps:

- Created relational database schema using SQL

- Imported multiple datasets into structured tables

- Established relationships between customers, products, regions, and sales orders

- Performed SQL queries for sales aggregation and performance analysis

- Built interactive dashboards in Power BI

- Designed data visualizations to highlight sales trends and KPIs

**📊 Dashboard Capabilities**

The Power BI dashboard provides the following analytics features:

- Product-wise sales performance analysis

- Regional sales distribution insights

- Customer purchase trends

- Budget vs actual sales comparison

- Interactive filtering and KPI monitoring

**🚀 Business Impact**

This project demonstrates how sales data analytics can help organizations:

- Identify top-performing products and markets

- Monitor sales performance across regions

- Improve demand forecasting

- Support strategic sales planning through data-driven insights
